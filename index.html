运作方式

从铸造到快照

  1. 01

    免费阶段：1,500 个名额

    Agent ID 持有人调用 mintFree() 免费铸造 1 张 NFT（金额 0.0001 BNB，仅为合约收取的费用，另加 Gas）。每个 Agent ID 限 1 张；名额用完或开售满 24 小时后，免费阶段结束。

  2. 02

    付费阶段：15,000 张

    免费阶段结束后自动开启付费铸造：每张 0.003 BNB，调用 mintPaid(数量) 一次可铸 1–10 张，每个 Agent ID 累计最多 10 张，总上限 15,000 张。

  3. 03

    收入直达金库

    全部铸造收入（免费费与付费款）在交易内直接转入 payee 金库地址 0xB5d7aec297705337F3e09Ec4F802a580EFfEa0D3 —— 没有流动性池分成、没有推荐分成、没有合约托管资金。合约不设提款通道，因为资金从不滞留合约。

  4. 04

    NFT 市场整张交易

    NFT 可在本站市场合约中按 tokenId 挂单、整张交易（见下方市场章节）。市场为非托管模式，手续费 2.5% 进入同一 payee 金库。

  5. 05

    第二阶段：快照分配代币

    OUTY 代币将在第二阶段创建。创建前先对 NFT 持有人做 快照：快照时每持有 1 张 NFT，即享有 30,000,000 OUTY 分配权益。快照时间将在第二阶段启动时提前公布。

收入不进合约、不分成 —— 直达 payee 金库。

免费铸造的 0.0001 BNB 与付费铸造的 0.003 BNB × 数量，都会在铸造交易内直接转入 payee 地址：0xB5d7aec297705337F3e09Ec4F802a580EFfEa0D3。没有 80/5/15 分成，没有资金池托管，没有推荐奖励扣留。

NFT 合约与市场合约均已通过 Sourcify 精确匹配（exact match）验证，源码公开可查。合约的 Agent ID 资格、免费/付费名额与每 ID 上限均由代码强制执行，不依赖人工审核。

常见问题

FAQ

什么是 Agent ID？为什么铸造需要它？

Agent ID 是 BNB Chain 上 AI Agent 的链上身份（源自 Binance Agentic Wallet 生态）。OUTY 第一阶段专为该生态设计：免费与付费铸造都要求钱包持有 Agent ID，资格由 NFT 合约在链上强制校验，没有 Agent ID 的钱包调用铸造会失败。

免费铸造为什么还要付 0.0001 BNB？

免费指的是 NFT 本身不另外收费；调用 mintFree() 时合约要求交易金额精确为 0.0001 BNB（100000000000000 wei），另加 BNB Chain 的 Gas。该费用与全部铸造收入一样，在交易内直接进入 payee 金库。每个 Agent ID 限 1 张，免费名额共 1,500 个，阶段窗口为 2026 年 11 月 13 日 08:00:20 至 11 月 14 日 08:00:20（北京时间），名额用完即提前结束。

付费铸造的规则是什么？

免费阶段结束后自动开启。每张 0.003 BNB，通过页面选择 1–10 张后调用 mintPaid(数量)，金额为 0.003 BNB × 数量。付费名额共 15,000 张，每个 Agent ID 累计最多 10 张（包含此前已铸造的数量），上限由合约强制。

铸造收入去哪了？有分成或资金池吗？

没有。全部铸造收入在铸造交易内直接转入 payee 金库 0xB5d7aec297705337F3e09Ec4F802a580EFfEa0D3 —— 没有流动性池分成、没有推荐分成，资金不滞留在合约内。

OUTY 代币现在能买吗？

不能 —— 代币尚未创建，任何自称 OUTY 代币的合约都不是官方的。代币属于第二阶段：将先对 NFT 持有人做快照，再按快照分配（每张 NFT 30,000,000 OUTY 的分配权益），分配概念与原定方案一致（总供应量 1T 固定；免费 NFT 对应 45,000,000,000、付费 NFT 对应 450,000,000,000、流动性池 360,000,000,000，剩余部分销毁）。

什么是快照？卖掉 NFT 还能拿到代币分配吗？

快照是在第二阶段启动时记录某一时刻全部 NFT 持有人与持仓的名单。分配按快照名单执行：快照时持有 NFT 才计入；快照之前已卖出的 NFT，其分配权益归买家所有。快照时间会提前公布，请留意本页与官方渠道。

NFT 可以在哪里交易？手续费多少？

通过本站市场合约 0x428f052AebAEA374074e4fBb1Fcb25EC2603b451 按 tokenId 挂单交易。市场为非托管模式，成交手续费 2.5%，进入 payee 金库。

NFT 的元数据在哪里？

合约的 baseURI 指向 https://outy.pages.dev/metadata/<tokenId>，每个 tokenId 对应一份标准 ERC-721 元数据 JSON。本页的 /metadata 视图给出了通用模板与示例。
